# .idea：PyCharm 项目设置

保存 IDE 的项目、解释器和版本控制配置，不参与模型计算。

- `cmit-2026-costume-verifier.iml`：项目模块、内容目录和解释器关联。
- `misc.xml`：Python SDK 及格式化工具设置。
- `modules.xml`：项目模块清单。
- `vcs.xml`：项目目录与 Git 的关联。
- [inspectionProfiles/](inspectionProfiles/README.md)：代码检查配置。
- `.gitignore`：排除工作区状态等本地文件。
- `workspace.xml`：窗口、最近操作等本机状态，不纳入 Git。

解释器路径与当前机器有关，换机器后需在 PyCharm 中重新选择。
