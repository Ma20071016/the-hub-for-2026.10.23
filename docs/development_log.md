## 模型与训练设置

| 模块 | 实现 |
| --- | --- |
| 编码器 | 两路共用冻结中文 BERT，保持 eval，输出 `[B,L,768]` 和有效位置 mask |
| 双路投影 | 独立 Linear `768 → 384`，投影后清零 padding |
| 立场模块 | 40 个共享原型，384 维，6 头单层交叉注意力；前馈 `384 → 768 → 384`，ReLU，dropout 0.3，两段 Pre-Norm 残差 |
| 融合与分类 | 每路平均池化，共用无偏置 `384 → 40`，拼接后 `80 → 180 → 3`，LeakyReLU(0.01) |

环境：WSL Ubuntu / Conda `escnet`，Python 3.10.21、PyTorch 2.7.0+cu128、Transformers 4.37.2、TensorBoard 2.21.0，RTX 5060 Laptop 8GB。

两次训练均采用 batch 16、max_length 64、seed 20261006、AdamW(lr=1e-4, weight_decay=0.01)、梯度裁剪 1.0，启用确定性算法；训练打乱、验证顺序读取，两路独立动态 padding，保留尾批。可训练参数 1,819,155 个，BERT 保持冻结。最多 10 轮，按验证 Macro-F1 优先、验证 loss 次优选最佳权重，连续 3 轮无提升停止。

每次实验保存 `run.json`、`metrics.jsonl`、`summary.json`、终端日志、每轮/最佳权重及 TensorBoard 事件。`last.pt` 另保留优化器和随机状态；权重只包含可训练下游模块，冻结 BERT 按固定版本另行加载。详细指标、来源与路径见[训练结果](../reports/training_results_2026-10-07.json)和 [runs 说明](../runs/README.md)。

## 2026-10-17：第一模块——审阅结果与覆盖范围

依据竞赛对标和项目诊断，按模块改进。第一模块完成结果表达与可追溯性，不改模型权重，也不把界面修正记作准确率提升。

- `/api/review` 升级为 `schema_version: 2`，统一 `results` 按正文顺序保存每句。状态区分模型支持 `supported`、疑似矛盾 `refute`、证据不足 `insufficient`、判定分歧 `conflicting`、未覆盖 `uncovered`；支持与反驳同时出现时保留分歧，信息不足和未检索到证据不再当作通过。
- 所有实际参与模型比对的证据保留原文、对象、出处、定位、预测与三类分数，界面可逐条展开。旧 `problems` 字段仅兼容反驳列表，完整结果以 `results` 为准。
- 返回 `normalized_text` 和 `offset_basis: normalized_text_python_chars`。每句起止位置使用清洗正文的 Python 字符下标，从0开始、含起点不含终点；不等于文件页码或 JavaScript UTF-16 位置。
- 统计正文句数、送入模型句数、五态计数、未覆盖原因和过滤片段数。覆盖率等于送入模型句数除以正文句数，不是准确率或稿件合格率；没有正文时覆盖率为 `null`，界面明确说明没有形成核验结论。
- 同时支持一次性 JSON 与 NDJSON 的 `start`、`sentence`、`done`/`error`。前端校验 schema、计数、状态及最终结果，流中断或缺失最终结果不会显示审阅完成。补充请求类型/长度校验，并修复流式响应头发送失败时模型锁未释放的问题。

### 实现范围

- 文稿可从文字型 PDF/DOCX 提取，也可直接粘贴、填写标题并编辑正文。完成模型审阅并成功保存后自动留档，保存失败不显示有可导出的成功记录。
- `backend/review_history.py` 使用独立本地 SQLite 文件 `data/review_history.db`，网站继续只读 `data/costume.db`。保存归一化正文、全部逐句结果、证据原文与出处、统计、创建时间及模型版本，不把新记录写入或改造原证据库中的旧核验表。
- 每句人工决定为“未处理 / 确认有误 / 保留原句 / 待补证”，可附最多2000字符备注。人工决定与模型预测分开，所有新记录初始为未处理；演示或测试中的意见不能当作专家审核结论或真实用户试用成果。
- 改稿后再次审阅生成新的 `review_id`，以 `parent_id` 关联原版本，不覆盖原正文、原证据及模型判断。新版本人工决定重新初始化；修改尚未复核时，页面明确旧结果仍对应已保存的版本，旧报告不混入新草稿。
- 档案可列出审阅摘要并重开完整记录，无需重新推理；证据库以后变化也不替换已保存的证据快照。尚未保存的人工意见须先保存或撤销，未复核文稿离开或替换时提示确认，浏览器离开页面有未保存修改保护。
- 人工意见采用 `expected_revision` 比较修订号，校验与写入在同一事务完成。旧页面保存返回409且不覆盖较新的意见，页面保留本地输入供使用者核对；这用于防止本机多页面误覆盖，不等于实现多人审批。
- 报告请求附带本页的人工意见修订号，过期返回409；后端校验与渲染使用同一份记录快照。前端在报告下载期间若又编辑或保存意见，会阻止旧报告下载并提示重新导出。
- 报告导出为自包含 HTML，可用浏览器打印另存 PDF；包含全部正文、五态、证据、出处、人工意见、未处理和未覆盖范围、模型及父版本标识。动态文字转义，只有绝对 HTTP(S) 来源地址可点击。
