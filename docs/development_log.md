# 开发记录

更新：2026-10-08（Asia/Shanghai）。

## 当前状态

基于 ESCNet 共享原型立场模块的文本三分类改编，已完成数据加载、文本模型、训练、验证、检查点保存与最佳权重回载检查。外部知识库检索、实体识别与链接、实体知识比较、图像分支、续训 CLI 和独立推理入口尚未实现。现有结果仅针对 OCNLI，不代表传统服饰领域效果或官方测试成绩。

## 模型与训练设置

| 模块 | 实现 |
| --- | --- |
| 编码器 | 两路共用冻结中文 BERT，保持 eval，输出 `[B,L,768]` 和有效位置 mask |
| 双路投影 | 独立 Linear `768 → 384`，投影后清零 padding |
| 立场模块 | 40 个共享原型，384 维，6 头单层交叉注意力；前馈 `384 → 768 → 384`，ReLU，dropout 0.3，两段 Pre-Norm 残差 |
| 融合与分类 | 每路平均池化，共用无偏置 `384 → 40`，拼接后 `80 → 180 → 3`，LeakyReLU(0.01) |

环境：WSL Ubuntu / Conda `escnet`，Python 3.10.21、PyTorch 2.7.0+cu128、Transformers 4.37.2、TensorBoard 2.21.0，RTX 5060 Laptop 8GB。

两次训练均采用 batch 16、max_length 64、seed 20261006、AdamW(lr=1e-4, weight_decay=0.01)、梯度裁剪 1.0，启用确定性算法；训练打乱、验证顺序读取，两路独立动态 padding，保留尾批。可训练参数 1,819,155 个，BERT 保持冻结。最多 10 轮，按验证 Macro-F1 优先、验证 loss 次优选最佳权重，连续 3 轮无提升停止。

## 训练结果

| 实验（2026-10-07） | 训练条数 | 完成 / 最佳轮次 | 最佳轮次的验证 loss | 准确率 | Macro-F1 | 耗时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `ocnli_3k_20261007_01` | 2,993 | 6 / 3 | 0.9614 | 53.63% | 0.5296 | 308.43 秒 |
| `ocnli_50k_20261007_01` | 37,072 | 9 / 6 | 0.8081 | 64.64% | 0.6495 | 3,115.83 秒 |

验证集均为 2,950 条，模型输入、标签和顺序一致；两份文件仅有 4 条 `group_id` 因分组上下文变化而不同。两次均因连续 3 轮无提升提前停止，时间上限分别为 40、60 分钟。总更新步数分别为 1,128、20,853；PyTorch 峰值 allocated 分别为 529.98、530.91 MiB。耗时和显存口径以各次 `summary.json` 为准。

50k 最佳轮次的类别 F1：支持 0.6365、反驳 0.7070、信息不足 0.6048。第 6 轮后训练损失继续下降，验证损失升高且 Macro-F1 未刷新，出现过拟合迹象。两次均通过最佳权重回载检查，固定验证 batch 的 logits 与保存时完全一致；此检查不等于实现断点续训。

每次实验保存 `run.json`、`metrics.jsonl`、`summary.json`、终端日志、每轮/最佳权重及 TensorBoard 事件。`last.pt` 另保留优化器和随机状态；权重只包含可训练下游模块，冻结 BERT 按固定版本另行加载。详细指标、来源与路径见[训练结果](../reports/training_results_2026-10-07.json)和 [runs 说明](../runs/README.md)。
