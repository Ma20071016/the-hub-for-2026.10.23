# 系统完善顺序（2026-10-17更新）

用户决定先完成产品与业务流程，将证据检索和模型可靠性改进放在最后。以下以往届国赛一等奖作品呈现的完整业务流程、可追溯数据、领域内容与可运行演示为对标方向；完成度按可操作的验收项判断，不以页面数量或奖项承诺代替验收。

目标使用者先聚焦传统服饰说明稿的编写者与审阅者。系统主线为：准备文稿 → 逐句审阅 → 核对出处 → 记录人工意见 → 修改复核 → 导出报告 → 回查历史。

| 顺序 | 模块 | 可操作的验收要求 |
| --- | --- | --- |
| 1（已完成） | 结果状态与证据 | 支持、疑似矛盾、证据不足、分歧、未覆盖分开；每句可查原文；覆盖率不作为准确率 |
| 2（已完成） | 审阅工作流程 | 正文可编辑；人工意见及备注可保存；修改后复核形成新版本；刷新后历史可恢复；导出的报告包含未处理与未覆盖内容 |
| 3（已完成） | 资料与服饰对象浏览 | 可以按名称/编号查找资料，查看对象、属性、原文、出处和适用范围；从资料进入审阅；可用资料数量来自真实数据库 |
| 4 | 系统使用与展示体验 | 导航和任务状态一致；电脑及移动窄屏可用；空状态、上传错误、断线和恢复有明确路径；启动与演示说明可复现 |
| 5 | 展示材料与实际使用记录 | 用真实来源和明确标识的示例演示完整流程；说明团队实现、复用部分和边界；整理用户实际试用记录，不代填未开展的试用结果 |
| 6（调整到最后） | 检索与模型可靠性 | 分离检索错误与模型错误；核对独立样本；检查输入及标签；必要时训练；用同一评测口径比较改进前后 |

当前阶段不调整模型结构、训练权重和检索阈值。所有模块继续保留第一模块的不确定性提示，人工意见单独记录，不改写历史模型预测。最后一阶段的可靠性验收仍是作品交付的一部分。

第二模块的历史采用独立本地 SQLite 文件 `data/review_history.db`。原有 `data/costume.db` 继续作为只读证据库使用。每次完成审阅保存正文、证据与预测快照，人工决定可另行更新；再次复核生成关联的新记录，不覆盖原稿。当前是本机单用户系统，未实现账号、跨设备同步或多人审批。

按用户后续建议，审阅档案已移至独立页面，工作台只呈现当前文稿与结果。档案页可搜索最近100条记录并按人工处理状态筛选，点击返回工作台继续复核；地址保留记录号以便刷新恢复。

第二模块已通过62项 Python 测试、15项前端流程回归及真实浏览器的审阅、人工意见、复核版本、刷新恢复和窄屏检查。HTML 报告下载与内容检查通过；浏览器工具拦截了本地 HTML 文件预览，报告打印版的视觉排版尚未验收。功能测试不代表模型准确率或实际用户试用结果。

第三模块已完成独立资料馆与详情页。真实数据库提供43份可用资料、99条已审核证据，支持检索与筛选、来源内对象分组、全文与证据定位、带资料进入审阅。新增22项 Python 测试、10组资料馆前端测试通过，工作台32项前端及既有21项 HTTP 回归通过；桌面与手机窄屏已检查。下一模块为系统使用与展示体验，模型与检索可靠性仍按第六阶段推进。

第四阶段已先完成“问题定位与改稿联动”：逐句结果可打开正文高亮与单句编辑面板，同屏查看原判定和证据；应用后标记待复核，复核形成新版本。重复句、Unicode 及跨句编辑采用保守定位，不能确认位置时保留原句依据并要求重新审阅。该项已做桌面、手机和临时历史库中的真实复核验证。

第四阶段随后完成“本机草稿自动暂存与恢复”：新文稿及每个档案分别存放，保存标题、正文、资料选择、未应用单句输入和未保存人工意见；恢复须显式选择，不自动修改档案。人工意见恢复使用原值、草稿值与档案最新值比较，冲突时提供备份及仅恢复文稿路径。暂存失败保留离页提醒，可导出 TXT。草稿限当前浏览器与站点，不等同于服务端留档；当前未提供跨设备同步。

用户随后选做优化清单的第四项“真实来源配图与局部标注”。已完成资料馆有图筛选和详情图文对照：5份馆方条目、9张保留完整画面及水印的图片、18个绑定已审核原文的编号位置；支持切图、放大、图文双入口及证据/原文定位。来源、馆藏编号、原图URL和哈希核对记录已保存。没有配图的资料不补虚构图片，也未增加模型图像识别功能。版本差异对比和报告版式完善仍是后续优化项。

第五项体验优化“首次使用引导与真实试用”已完成工具部分：新增 `guide.html` 使用指南，说明六步流程、五态结果、保存位置及常见问题；工作台提供按当前状态变化的下一步提示和显式载入的“【教学示例】”。示例通过当前来源、URL、对象及两条唯一原文校验后载入，不覆盖已有文稿、档案或待恢复草稿，不自动运行模型。指南支持手动记录六步实际体验、卡点与建议，仅在当前浏览器保存一条反馈，支持显式恢复和 TXT/JSON 导出，不自动上传。工具测试已通过；真实人员试用、实际浏览器视觉验收及后续试用结果整理尚未完成。本项属于前述五项体验优化清单，不表示本路线图第五阶段“展示材料与实际使用记录”已全部完成。
